# Evidencija – Home Assistant add-on

Evidencija za lovačke udruge kao Home Assistant add-on: članovi, radne akcije, **kalendar termina**, **članarina u ratama**,
imenik s dijeljenjem kontakata, poruke među članovima, oglasnik, WhatsApp/Viber, ikona na početnom zaslonu mobitela.

Add-on pokreće PHP verziju programa [lovacka-evidencija](https://github.com/daxemann/lovacka-evidencija) (Apache + PHP 8.3) s javnom HTTPS adresom preko Tailscale Funnel.

**Instalacija:** Home Assistant → Postavke → Dodaci (Apps) → Trgovina → ⋮ → Repozitoriji → dodati
`https://github.com/daxemann/evidencija-addon` → instalirati **Evidencija (lovačka udruga)**.

Upute: [evidencija/DOCS.md](evidencija/DOCS.md)

Repozitorij sadrži samo program – nikakve podatke članova.
